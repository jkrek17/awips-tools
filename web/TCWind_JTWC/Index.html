Time history: Vmax (black) and Rmax (gray dashed, right axis) vs forecast hour. Colored bands are each threshold's quadrant min-max range (the wider the band, the more asymmetric the bulletin's own radii are) with the quadrant mean as a line. Vertical line marks the currently selected time.
Azimuthal profile at the selected time: modeled wind speed vs radius along each quadrant bearing. Dots are the bulletin's own reported radii - a dot sitting on its line is a good fit; off the line means the interpolation is straying from what JTWC reported. In Archived Cases, a dashed gray Holland curve also appears: an independent model anchored the same way (same Vmax/Rmax/R34). Where it and the colored lines pull apart is genuine disagreement between two reasonable models, worst just outside the core.

What this is

  • Archived Cases replays one real storm's JTWC post-season best-track reanalysis — not a live bulletin — through this same map/diagnostics view, so the tool's output can be checked against the later-corrected, true answer.
  • See the Findings page for where this data comes from and what we've learned from it in aggregate across ~16,000 records.

How to read the map, once a storm is picked

  • Dashed line — the storm's full track; dots along it — each reported position, colored by intensity at that time (same colors as the wind field below). The larger black-ringed dot is the storm center at the selected time — step through them with the ◀ ▶ buttons or the ← → arrow keys.
  • Solid red/orange/yellow rings — JTWC's own reported 64/50/34-kt wind radii (ground truth).
  • Colored raster — the tool's modeled wind field, built from those same radii.
  • The solid rings are already an interpolation, not the raw report: JTWC only gives one number per quadrant, smoothly blended between quadrant centers here. Turn on Reported radii (literal) in the toolbar to see each quadrant's own number held flat across its full 90° span instead, stepped at the compass boundaries - the actual, unprocessed input, laid directly over both the smooth ring and the raster.
  • Magenta dashed ring — actual reported RMW.
  • Teal dashed ring — actual ROCI, a pressure-based size measure, not directly comparable to a wind radius (see Findings for the caveat).
  • What matters: where the raster's bright core sits relative to the magenta ring, and how far it fades out relative to the teal ring.
  • In Diagnostics, the azimuthal-profile chart also overlays an independent Holland (1980) curve for the selected storm/time.
